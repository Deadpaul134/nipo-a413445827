# Control room

A static control room page for a video series and the project it documents.
It is served by GitHub Pages from the `main` branch.

- `index.html` is generated by the project's build script. Do not edit it by hand.
- `data/` holds the live data. The page reads it at run time and writes it through the
  GitHub Contents API, with an access key the viewer pastes into the page. The key is
  kept only in that browser's local storage and is never committed.

## Data

Each collection is one JSON file. The file is an object keyed by document id; each value
is the document, without an `id` field.

| File | Documents |
|---|---|
| `data/agents.json` | One status per agent: `lastDone`, `lastAt`, `waitingOn`, `history` (newest first, at most 30 of `{at, text}`), and `team` for agents outside Claude |
| `data/requests.json` | Instructions to an agent: `to`, `text`, `status` (waiting, picked, done, cancelled), `createdAt`, `pickedAt`, `doneAt`, `result`, `cancelledAt` |
| `data/approvals.json` | Decisions for the user: `from`, `to`, `title`, `detail`, `status` (pending, approved, rejected), `createdAt`, `decidedAt`, `note`, `episode`, `handledAt` |
| `data/tasks.json` | Things only the user can do: `text`, `note`, `source`, `sourceIds`, `episode`, `blocking`, `status` (open, done, cancelled), `createdAt`, `doneAt`, `doneBy`, `reportedAt` |
| `data/grokDecisions.json` | Decisions reported on the user's behalf: `text`, `by`, `episode`, `createdAt`, `objected`, `objectedAt` |
| `data/checks.json` | `{ "items": { "<task id>": { "done", "at" } } }` for the episode task checkboxes |

All times are ISO 8601 in UTC, ending in `Z`.

## Rules

- Everything here is public and can appear on camera: no personal details, names or amounts.
- Viewer questions, brands and orders never go into this repository.
- Agents change data with a pull, an edit, a commit and a push. The page commits one
  document change at a time and retries on a sha conflict.
